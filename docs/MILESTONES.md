# Delivery milestones

Each milestone has one tracking issue and one linked pull request. Feature branches use `feat/`. Pull requests include acceptance criteria and validation evidence, and close their issue when merged.

1. **Foundation** — React, strict TypeScript, Vite, Tailwind, reusable shadcn-style button, types, history, geometry, local image processing, input validation, favicon, SEO, and Vercel configuration.
2. **Landing and upload** — Dribbble-inspired responsive landing page, local font assets, reusable drag/drop uploader, clipboard paste, sample screenshot, routes, and in-memory image lifecycle.
3. **Editor and secure export** — Pointer drawing, selection, movement, corner resizing, effects and settings, undo/redo, keyboard controls, compare, zoom, reset confirmation, flattened PNG downloads, mobile toolbar, and optional privacy checklist.
4. **QA and release** — Pure-function tests, browser pixel and export checks, privacy review, CI, README, deployment packaging, and documented limitations.

## Design references

- [Ramotion — HackerRank landing page](https://dribbble.com/shots/26414267-B2B-SaaS-Landing-Page-Design-for-HackerRank): bold typographic hierarchy and restrained green accents.
- [Diana Larussa — Minimal photo editor](https://dribbble.com/shots/27300066-Photo-Editor-UI-Minimal-Web-App-Design-Image-Editing-Dashboard): spacious canvas and grouped right-side controls.

These references informed composition and hierarchy. The MaskMate brand, copy, receipt illustration, colors, and implementation are original to this project.
